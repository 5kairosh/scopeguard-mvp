# ScopeGuard

IT жобаларындағы қосымша талаптарды бағалау және клиентпен келісуге арналған MVP.

**Қазақша · Русский · English**

## Мүмкіндіктер

- Жоба құру, бастапқы талаптар, бюджет және дедлайнды сақтау.
- Қосымша талапқа өзгеріс сұрауын тіркеу.
- Жұмыс сағаты, тариф және қосымша күндерді бағалау.
- Мақұлдау алдында қазіргі және ұсынылған бюджет пен дедлайнды салыстыру.
- Клиенттің мақұлдауы немесе қабылдамауы.
- Тек мақұлданған өзгерістерді бюджет пен мерзімге қосу.
- Шешімдер тарихы және JSON экспорты.
- Үш тілдегі интерфейс және телефонға бейімделген көрініс.

## Жергілікті іске қосу

`index.html` файлын браузерде ашыңыз. Пакеттер орнату қажет емес.

Технологиялар: HTML, CSS және JavaScript. Деректер `localStorage` арқылы браузерде сақталады.

## Тесттер

Node.js орнатылған ортада:

```sh
node --test tests/model.test.cjs tests/i18n.test.cjs
```

Тесттер келісуді, қабылдамауды, бюджет пен дедлайн есептерін, қате бағалауды және үш тілдегі сөздіктердің толықтығын тексереді.

## Демонстрация

1. Бастапқы бюджеті 500 000 ₸, дедлайны 2026-11-01 болатын жоба құрыңыз.
2. «Онлайн чат қосу» өзгерісін тіркеңіз.
3. Менеджер рөлінде 10 сағат × 5 000 ₸, қосымша 2 күн деп бағалаңыз.
4. Клиент рөліне ауысып, сұрауды мақұлдаңыз.
5. Жаңа бюджет 550 000 ₸, жаңа дедлайн 2026-11-03 болады.

## GitHub Pages

Статикалық файлдар репозиторийдің түбірінде орналасқан. Pages баптауы: `Deploy from a branch`, `main`, `/(root)`.

## MVP шектеулері

Бұл нұсқада рөл ауыстыру — демонстрация, аутентификация емес. Жеке аккаунттар, серверде рұқсаттарды тексеру және ортақ дерекқор әлі қосылмаған. Әр пайдаланушының деректері тек өз браузерінде сақталады. Басқа домендегі нұсқаға өткенде бұрынғы браузер деректері автоматты көшпейді.

Қосымша күндер календарлық күндер ретінде ретімен қосылады; қатар орындалатын жұмыстар мен демалыс күндері жеке есептелмейді. Пайдаланушы енгізген мәтіндер автоматты аударылмайды.
